# Visual & UX Recommendation: geektion.com

## 1. Visual Aesthetic: "Technical Premium"
Inspired by **avinox-ebike.com** (Industrial Tech) and **fazua.com** (Seamless B2B).

- **Color Palette**: 
    - Primary: **Graphite Black (#1A1A1A)** and **Electric Silver (#E5E5E5)**.
    - Accent: **Cyber Blue (#00A3FF)** or **Industrial Orange (#FF6B00)** for call-to-actions and "Hero Specs".
- **Typography**: 
    - Headlines: A modern Sans-Serif with wide tracking (e.g., *Inter* or *Space Grotesk*) to convey engineering precision.
    - Mono-spaced fonts for technical parameters to evoke a "spec-sheet" feel.
- **Imagery**: 
    - Macro photography of motor internals, CNC-machined surfaces, and clean welding seams.
    - Ghosted / X-ray views showing how the drive system integrates into the frame.

## 2. UX Strategy for B2B

### A. Spec-First Discovery
B2B buyers care about parameters (Nm, Wh, Weight). 
- **Recommendation**: Implement a "Sticky Spec Bar" on product pages that stays visible while scrolling, displaying core KPIs.
- **Comparison Engine**: A tool to compare two motor systems or battery configurations side-by-side.

### B. Integration Focus
- **Interactive Integration Map**: A "Build your System" visualizer where users can click on a motor and see compatible batteries and displays light up.
- **OEM Timeline**: An interactive vertical timeline for the OEM service page showing the journey from "Concept" to "Global Shipping".

### C. Reduced Friction for Inquiries
- **Contextual Inquiry**: Every product page should have a "Request Technical Data / Quote" button that pre-fills the product name in the contact form.
- **Document Hub**: A "One-Click" zip download for all technical assets (STEP, PDF, Manuals) for registered partners.

## 3. Mobile Performance
- High-performance B2B buyers often browse during trade shows or transit.
- **Astro Implementation**: Leveraging Astro's Islands architecture to ensure the heavy tech-spec tables and comparison tools load instantly without blocking the main content.
